About the project

The current prototype runs locally and supports a private idea bank, a media library and draft scheduling for TikTok and Instagram. Social-account authorization, direct publishing and analytics are planned features, not currently active.

The project is not affiliated with, endorsed by, or operated by TikTok, Instagram or Meta. Public access to this website does not provide access to the private application.
