Privacy Policy

STELVÉRA Manager · Last updated: November 22, 2026

1. Scope and current status

This policy describes the STELVÉRA Manager prototype associated with Moon Music Label and this public informational website. The current private application runs locally on an operator-controlled computer. Connections to TikTok and Instagram are planned but are not currently enabled.

2. Information handled by the prototype

The current prototype may store content ideas, text descriptions, publication drafts, proposed posting dates, local video files and technical file identifiers in its local database and folders. The prototype does not currently retrieve TikTok or Instagram account data through their APIs.

3. Purposes

These materials are used to organize creative work, preview media, plan publication drafts and test application functionality. They are not automatically published to social platforms by the current prototype.

4. Storage and third parties

Application content is currently stored on the computer hosting the private prototype. This publicly accessible website is hosted using GitHub Pages; accessing it is subject to GitHub's own service infrastructure and policies. If social-media or cloud services are connected later, this policy will be updated to describe the data accessed, transfers, retention and permissions before those integrations are launched.

5. Access, deletion and security

The operator controls access to the local prototype and its stored files. The prototype has not yet implemented a separate user login or self-service data deletion interface, and must not be exposed publicly in its current form. Requests concerning stored materials, access or deletion can be directed through the Moon Music Label contact page. No security system can eliminate every risk.

6. Future TikTok and Instagram integration

Any future connection would require users to authorize the relevant platform permissions. The precise data collected, use of credentials or tokens, retention periods, withdrawal procedures and deletion process must be disclosed here before public operation. No such connection is active at this time.

7. Policy changes

This notice may be updated as the service changes, particularly before any production integration or broader public rollout. The date above indicates the latest published version.
